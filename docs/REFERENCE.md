## 핵심 사실

| 주제 | APT / EE2 | PoE Overlay | 우리 (현재) |
|---|---|---|---|
| 필터 기본값 | 일반 아이템: 값 ±10% (설정 0~50). 고유: 롤 범위 폭의 10%. 최대롤/타락 매직은 정확값. stat 마다 `better` 방향 있어서 min 만 / max 만 / 둘 다 결정 | 수동 튜닝 규칙으로 방향 결정. 프로필: 빠른 가격 / 정확히 일치 / 넓게 / 제작 베이스. "확장(-10%)" 정확한 규칙은 확인하지 못했습니다 | 값 그대로 min. 역방향 27개만 max |
| 자동 체크 | Exact 프리셋에서 T1~T2 explicit 자동 체크 | 모드 점수 >3 상위 4개 자동 체크 | 우클릭 등록(Checked.txt)된 것만, 등급 알면 T1~T2 만 |
| 롤 % | goodness = (값-min)/(max-min) | 고유 롤 %, pseudo 롤 % | 없음 (고급 설명 범위를 버리고 있습니다) |
| 옵션 매칭 | 언어별 `stats.ndjson` 매처: 숫자 없는 문구에 고정 value 매핑 (예: "명중 시 적 실명 유발" → value 100). 게임 데이터 + 거래소 데이터로 생성 | 비공개 | 거래소 stat 텍스트 정규화 매칭 + 영어 "100% chance to" 재시도 + 별칭표 |
| 리스팅 | 가격/스택/ilvl/젬레벨/퀄리티/등록시간/(판매자). AFK·오프라인 점, 덤프탭 가격 '?' | 정렬 가능 컬럼, 즉시구매/귓말 구분, 오래된 매물 흐리게, 아이템 툴팁 미리보기 | 텍스트 목록 (가격 [계정] 경과시간) |
| 기본 거래 조건 | 계정별 묶기(collapse), 즉시구매만 | 즉시구매 기본, 화폐/온라인/등록일 기본 필터 | 즉시구매+직접거래(available), 등록일 1주 |
| 가격 요약 | poe.ninja 환율로 chaos↔div 자동 표기 | 자체 ML 추정가 + 범위 + 신뢰도 | 최저~최고 + 최빈 2개 (화폐가 섞이면 부정확합니다) |
| 화폐 환율 | poe.ninja 31분 주기. 카카오도 글로벌 시세를 사용합니다 | 확인 못 함 | 없음 |
| 벌크 | 체크된 stat 없고 교환 가능 아이템이면 자동으로 exchange API | 화폐거래소 아이템만 벌크, 벌크↔단일 전환 | 교환 콤보에서 화폐 고르면 교환 시세 |
| 레이트 리밋 | 헤더 동기화, 1.5초 넘게 기다려야 하면 바로 에러 | 상태를 UI 에 표시 | 헤더 동기화, 큐에서 대기 (3초 넘으면 문구 표시) |
| 채팅 | F5 /hideout, F9 /exit, @last 치환, 한 키 한 명령 | F5 /hideout, F6 /dnd | F2 /hideout, F4 /exit, ^{Enter} 귓말 답장 |
| 형태 | 게임 창에 붙는 오버레이 | 오버레이 | 항상 위 팝업 (포커스를 빼앗지 않습니다) |

## 2026-11-27 재조사 (코드 분석)

APT(master), Exiled Exchange 2(v0.16.3) 소스와 PoE Overlay(PoE1) 체인지로그·기능 페이지, PoE Overlay 커뮤니티 포크 소스를 다시 확인했습니다.

### 기본값 비교

| 항목 | APT | EE2 | PoE Overlay 포크 | 우리 |
|---|---|---|---|---|
| 등록 기간 | 지정 안 함 (언제든) | 지정 안 함 (언제든) | 3일 | 자동: 즉시 구입만이면 언제든, 직접 거래 포함이면 3일 |
| 판매 방식 | 즉시 구입만 | 즉시 구입만 | 즉시 구입 + 직접 거래 | 즉시 구입만 |
| 가격 화폐 | 지정 안 함 (소모품만 chaos_divine) | 지정 안 함 | chaos + divine | chaos_divine / PoE2 exalted_divine |

즉시 구입 매물은 판매자가 오프라인이어도 살 수 있으므로 오래된 매물도 유효합니다. 그래서 즉시 구입만 볼 때는 등록 기간을 제한하지 않습니다.

### 반영했습니다 (v0.0.9)

- PoE2 훼손 옵션을 수정 가능한 아이템이면 일반(explicit) id 로 검색합니다. (EE2 `create-stat-filters.ts`) 분열 옵션은 v0.0.18 부터 다시 분열 id 로 검색하고, 분열된 아이템이면 기본으로 켭니다. 일반 id 로 찾으면 분열 안 된 매물까지 섞여서 시세가 틀어졌습니다 (카카오 실측: 분열 28개 vs 일반 2152개).
- 기본 제외 필터: 고유 아닌 장비는 복제된(`mirrored=false`) 매물과, 영구 리그가 아니면 분할된(`split=false`, PoE1) 매물을 제외합니다. 정확 프리셋은 분열 아닌 아이템이면 `fractured_item=false` 를 넣습니다. (APT `createTradeRequest`)
- 속성 자동 체크: 방어 종류가 하나뿐인 베이스면 그 속성을, 무기는 물리/원소 비중 67% 기준으로 물리·원소·전체 DPS 를 켭니다. 켠 속성에 이미 들어간 로컬 옵션은 체크를 해제합니다. (APT `item-property.ts`)
- 고유: 고급 설명에서 범위가 없는 고정 롤은 체크하지 않습니다. (APT `hideNotVariableStat`)
- 클러스터 주얼: 패시브 개수별 범위(4 → 4~5, 2·8·9·레어 5 → 최대값만, 나머지 → 최소값만), 주얼 홈 수 해제, 아이템 레벨 구간 1/50/68/75/84. (APT `applyClusterJewelRules`)
- 젬: 품질은 16 이상(변형 젬 20 이상)일 때 체크합니다. PoE2 는 레벨 19 이상이면 레벨을 체크합니다.
- 같은 판매자가 같은 가격으로 연달아 올린 매물은 한 줄로 묶고 ×N 으로 표시합니다. 추정가 계산에는 판매자당 2개까지만 넣습니다. (APT `groupedResults`, PoE Overlay 포크 `item-search-analyze.service.ts`)
- 같은 조건을 1분 안에 다시 조회하면 요청하지 않고 저장한 결과를 보여 줍니다. (APT `trade/Cache.ts`)

# 개발 문서

원본 대비 바뀐 점과 뺀 기능은 [FEATURES.md](FEATURES.md), 다른 도구와의 비교는 [REFERENCE.md](REFERENCE.md)를 참고하세요.

## 원칙

이 프로그램의 목표는 **가볍고 빠른 것**입니다 (사용자 결정). 기능을 더할 때는 시작 시간, 팝업이 뜨는 속도, 메모리, 요청 수를 늘리지 않는지 먼저 봅니다. 자주 쓰지 않을 기능이나 화면을 복잡하게 만드는 요소는 넣지 않고, 이미 넣은 것도 쓸모가 적으면 뺍니다 (예: v0.0.37 최근 아이템 ◀/▶ 제거).

## 빌드 (Windows)

필요: Qt 6.5 이상 (MSVC 2022 64bit 또는 MinGW 64bit), CMake 3.21 이상, Ninja 권장

```bat
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:\Qt\6.8.3\msvc2022_64
cmake --build build
C:\Qt\6.8.3\msvc2022_64\bin\windeployqt.exe build\PoeTradeSearch.exe
```

데이터 폴더는 `PoeTradeSearch.exe` 옆의 `data\`입니다. 쓰기가 불가능한 위치라면 `%APPDATA%\PoeTradeSearch`를 사용하며, 환경 변수 `PTS_DATA_DIR`로 직접 지정할 수도 있습니다.

## 리눅스에서 개발 / 테스트

리눅스에서는 플랫폼 계층이 스텁이라 게임 감지와 단축키는 동작하지 않지만, 파서·쿼리·네트워크·UI는 그대로 동작합니다.

```sh
cmake -S . -B build -G Ninja && cmake --build build

# 거래소 데이터 받기 (data/cache/... 에 저장)
./build/pts_cli --data ./data --update --game poe1 tests/fixtures/poe1_en_rare_ring.txt

# 단위 테스트 (파서 테스트는 실데이터 필요, 없으면 SKIP)
PTS_TEST_DATA=./data ./build/test_core

# 아이템 텍스트 하나 파싱해서 쿼리 보기 / 실제 검색 / 시세
./build/pts_cli --data ./data --league Standard tests/fixtures/poe1_en_rare_sword.txt
./build/pts_cli --data ./data --league Standard --price 20 tests/fixtures/poe1_en_unique.txt

# 화면 없이 팝업 렌더링 확인
QT_QPA_PLATFORM=offscreen PTS_DATA_DIR=./data PTS_DEV_ITEM=tests/fixtures/poe1_ko_rare_ring.txt \
  PTS_DEV_SHOT=/tmp/popup.png ./build/PoeTradeSearch
```

## 구조

```
src/core      파서(ItemParser), 거래소 DB/stat 인덱스(TradeDb), 쿼리(QueryBuilder), 설정, 자동 체크
src/net       레이트 리밋 큐(TradeClient), 데이터 캐시(DataManager), 엔드포인트, 업데이터
src/platform  Windows: 포그라운드 감지 / SendInput / RegisterHotKey / WS_EX_NOACTIVATE (그 외 OS 는 스텁)
src/ui        팝업, 옵션 행, 설정, 단축키 입력
resources     parser.json (한/영 키워드, 아이템 종류 매핑, pseudo 매핑 등), 아이콘
packaging     Inno Setup 설치 스크립트
tools         pts_cli (디버그용), make_icon
```

`resources/parser.json`을 데이터 폴더에 복사해서 수정하면 그 파일이 우선 적용됩니다. 한국어 클라이언트 문구가 인식되지 않는 경우 이 파일만 수정하면 됩니다.

원본의 `Config.txt` / `Checked.txt`도 그대로 읽습니다. 예전 설정은 처음 실행할 때 자동으로 변환됩니다 (`{Wiki}`/poe.ninja 단축키 삭제, `/hideout`·`/exit`·`{Last}` 추가).

## 외부 데이터

- 거래소 데이터: GGG / 카카오 공식 trade API (`/api/trade(2)/data/*`), 자동 다운로드·캐시
- 옵션 매처: APT (PoE1) / Exiled Exchange 2 (PoE2)의 `stats.ndjson` (MIT). 저장소에는 포함하지 않고 데이터를 갱신할 때 받아서 `data/cache/<game>/<lang>/matchers.ndjson`에 저장합니다. 받지 못해도 기본 매칭은 동작합니다.
- 환율: 거래소 일괄 교환 시세로 직접 계산합니다 (30분 캐시, poe.ninja는 사용하지 않습니다).
- 아이콘: `web.poecdn.com`

## 아이콘 수정

`resources/app.svg`를 수정한 다음 아래 명령을 실행합니다.

```sh
cmake -S . -B build -DPTS_BUILD_TOOLS=ON && cmake --build build --target make_icon
QT_QPA_PLATFORM=offscreen ./build/make_icon resources/app.svg resources/app.ico resources/app.png
```

## 릴리즈

master 푸시와 PR에서는 GitHub Actions가 Windows 빌드와 테스트만 수행합니다 (결과물은 Actions 아티팩트). 릴리즈는 `v*` 태그를 붙일 때만 만들어집니다.

```sh
# CMakeLists.txt 의 project(... VERSION x.y.z) 도 같이 올리기
git tag v0.0.50
git push origin v0.0.50
```

Release에는 `PoeTradeSearch-Setup.exe`, `PoeTradeSearch-win64.zip`과 각각의 `.sha256` 파일이 올라갑니다.

### 앱 업데이트 동작

- GitHub `releases/latest`를 시작 15초 뒤와 이후 6시간마다 확인합니다.
- SHA256을 검증한 뒤 앱을 종료합니다. 설치판(설치 폴더에 `unins000.exe`가 있는 경우)은 새 Setup.exe를 `/VERYSILENT`로 실행하고, 포터블은 PowerShell로 zip을 덮어쓴 뒤 다시 실행합니다.
- 자동 설치는 배포 빌드(`PTS_RELEASE_BUILD`)에서만 동작합니다. 직접 빌드한 버전은 알림만 표시합니다.
- 실패하면 기존 버전으로 다시 실행되고 `data\update\update.log`에 사유가 기록됩니다.

## 아직 검증하지 못한 것

- 한국어 클라이언트 신규 문구 일부(역병에 유린당한, 삿된, 경로석 등급, PoE2 한글 아이템 종류)는 거래소 필터 텍스트를 기준으로 한 추정값입니다.
- PoE2 클립보드 형식은 `Requires: Level ...` 한 줄 요구 사항을 기준으로 판별합니다.
- `server_redirect` 모드(`/trade/search/{league}?q=`)
- 다른 언어 서버로 검색(한글 아이템 → 글로벌): 거래소 items 목록 순번으로 매칭하므로, 한/영 목록 길이가 다른 그룹은 실패합니다.

### v0.0.49

- 아이템 검색({Run}) 기본 단축키를 Alt+D 에서 Alt+E 로 바꿨습니다 (사용자 결정). PoE2 는 WASD 로 이동하므로 D 가 게임 입력과 겹칩니다. 설정 버전 10 이전에 예전 기본값(Alt+D) 그대로인 설정은 Alt+E 를 다른 단축키가 쓰지 않을 때만 옮깁니다. 직접 바꾼 키(예: Ctrl+C)는 그대로 둡니다. [설정](../src/core/Config.cpp)
- 설정 창 안내문, 데이터 준비 중 알림, README 의 단축키 표기를 Alt+E 로 바꿨습니다.

**검증.** `runHotkeyMigration` 에 v10 이전 사례 3가지(Alt+D → Alt+E, Alt+E 가 이미 쓰이면 유지, Ctrl+C 유지)와 기본값 Alt+E 확인을 넣었습니다. 코어 테스트 78개, UI 테스트 9개가 통과했습니다.

**남은 확인.** Windows 실기 PoE2 에서 Alt+E 가 게임에 먹히지 않고 검색되는지.

### v0.0.48

코드 감사(사용자 요청). 다른 회사 모델 둘에게 읽기 전용으로 나눠 맡겼습니다: Sol 6.2 high(src/core, src/ui), Neon high(src/app, src/net, src/platform, main.cpp, 설치/CI). 리더가 지적마다 재현 테스트를 먼저 만들고, 수정을 빼면 실패하는 것을 확인한 뒤 고쳤습니다.

코어/팝업 (Sol):
- 희귀도 조건을 끄면 고유 아이템 이름이 검색에서 빠지던 문제. 희귀도를 안 보내도 고유면 이름을 보냅니다. [QueryBuilder](../src/core/QueryBuilder.cpp)
- 범위(일치/-N%)를 바꾸면 손으로 바꾼 체크가 초기화되던 문제. 지금 체크 상태를 유지하고 최소/최대만 다시 계산합니다. [팝업](../src/ui/MainPopup.cpp)
- PoE2 경로석에 아이템 레벨 줄이 두 번 나오던 문제. [파서](../src/core/ItemParser.cpp)
- 일치 프리셋에서 "분열 아님" 조건을 끌 수 없던 문제. [SearchDefaults](../src/core/SearchDefaults.cpp)
- 이름·베이스를 둘 다 끈 분류 검색인데도 번역 실패로 서버가 바뀌던 문제. 글자를 실제로 보낼 때만 번역합니다.
- 한국어 경로석이 PoE1으로 판정되던 문제. 분류 이름을 영어로 바꿔 비교합니다. [Keywords](../src/core/Keywords.cpp)
- 같은 가격·판매자의 일반/교환 줄이 ×N으로 합쳐지던 문제. 등록 시간을 뺀 모든 칸과 가격으로 묶습니다.
- 가격 메모가 12.25 를 12.3 으로 반올림하던 문제. 소수 넷째 자리까지 그대로 씁니다. [PriceSummary](../src/core/PriceSummary.cpp)
- 새 아이템을 띄워도 이전 결과의 "더 불러오기" 상태가 남아, 빈 표에서 휠을 굴리면 요청이 나가던 문제.
- 자동 체크 최소 레벨 규칙이 부분 문자열로 맞춰져 `Fingerless Silk Gloves(84)`가 `Silk Gloves`에도 걸리던 문제. 베이스 이름을 정확히 비교합니다. [CheckedStore](../src/core/CheckedStore.cpp)
- 설정 JSON에서 끝 쉼표 뒤에 `//` 주석이 있으면 읽지 못하던 문제. [JsonUtil](../src/core/JsonUtil.cpp)

앱/네트워크/Windows (Neon):
- 교환 응답이 JSON이 아니면(차단 페이지 등) 빈 결과가 캐시되고 오류도 안 보이던 문제. 형식을 검사해 오류로 알립니다. [TradeClient](../src/net/TradeClient.cpp)
- fetch 결과의 이름에 붙은 `<<set:MS>>` 태그를 떼지 않아 아이콘 학습이 어긋나던 문제.
- 거래소 웹 열기 주소에서 `+`, `%` 가 인코딩되지 않아 서버가 다른 글자로 읽던 문제. [Endpoints](../src/net/Endpoints.cpp)
- 업데이트 적용이 겹쳐 두 번 설치될 수 있던 문제, 더 새 버전이 나와도 이전에 받은 zip을 쓰던 문제, 받는 중에 설치를 누르면 엉뚱한 경고가 뜨던 문제. 설치 실패 시 임시 폴더를 지웁니다. [앱](../src/app/Application.cpp) · [Updater](../src/net/Updater.cpp)
- 데이터 폴더가 없으면 잠금 파일을 못 만들어 "이미 실행 중"이 잘못 뜨던 문제. 시작 시 폴더를 만듭니다. 로그 기록을 잠금으로 보호합니다. [main](../src/main.cpp)
- 첫 시세 조회 중 팝업을 닫았다 다시 열면 "시세 확인중..."에 멈춰 있던 문제. 취소 안내를 띄우고 클릭하면 다시 조회합니다.
- 화면 정보를 못 얻으면 팝업 위치 계산에서 죽을 수 있던 문제.
- 오른쪽 Alt/Ctrl/Win 을 보낼 때 확장 키 플래그가 빠지던 문제. [WinPlatform](../src/platform/win/WinPlatform.cpp)

고치지 않은 지적: 요청 한도 기록 시점(보낸 시각 기준, 의도한 설계), `{Run}`이 클립보드를 비우는 것(의도한 동작), 쓰기 권한 없는 설치 폴더용 zip 대체 경로.

구조 개선 제안(이번엔 적용 안 함, 가볍고 빠르게 원칙에 맞춰 필요할 때만): Application.cpp에서 시세 조회를 PriceController로 분리, 팝업 편집 상태를 ItemFilterState 하나로 통일, ItemParser::parse를 단계별 함수로 분리, 시세 줄을 문자열 목록 대신 작은 값 타입으로.

**검증.** 코어 테스트 `auditCoreFixes`, `auditNetFixes`, UI 테스트 `auditPopupFixes`를 더했습니다. 수정을 하나씩 빼고 돌려 각각 실패하는 것을 확인했습니다. 코어 테스트 78개, UI 테스트 9개가 통과했습니다. 확장 키 수정은 Windows 전용이라 CI 빌드로만 확인합니다.

**남은 확인.** Windows 실기에서 단축키(오른쪽 Alt 조합), 업데이트 한 번만 설치되는지, 범위 바꿀 때 체크 유지.
